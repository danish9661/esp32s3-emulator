On-device coverage

Every ESP32-S3 feature the project tracks, what the emulator models, and what is deliberately left out. “Validated” means a real arduino-cli sketch boots in the emulator and its serial output plus internal state are asserted by the battery.

CPU

FeatureStatusRemark
LX7 base ISAValidatedALU, loads/stores, branches, CALL0/J loops, windowed registers, exceptions, interrupts.
ee.* DSP/TIEValidated218/218 execute incl. ee_srs_accx; unmapped patterns trap loud (correct).
Single-precision FPUValidatedFull libgcc __divsf3 / sqrtf sequences bit-exact vs host f32.
Dual core + cross-core IRQValidatedPRID strapping, serialized stepping, cross-core yields; FreeRTOS SMP boots.

Connectivity

FeatureStatusRemark
Wi-Fi scanValidatedHost-completed scan at the firmware boundary; SSID/RSSI/chan/BSSID asserted.
Wi-Fi station connectValidatedAssociation + GOT_IP + status/IP/SSID/RSSI prints + disconnect leg.
Wi-Fi SoftAPValidatedsoftAP() init + STARTED bits, softAPIP 192.168.4.1, MAC, station count 0; no over-the-air peers (single node).
ESP-NOWValidatedInit/peer/send + in-firmware TXCB/RXCB via virtual second node (no RF; direct C-call delivery).
Live IP backhaul (L3–L7)Out of scopeGo SLIRP/NAT gateway exists (tools/gateway, DHCP/DNS/ARP/IPv6-RA/UDP-forward); no emulator-side Ethernet bridge feeds it frames yet.
Bluetooth / BLEOut of scopeRadio + controller stack; months of work, not required for the milestone.
